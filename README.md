# 🌷 Toko Bunga

Toko Bunga adalah website sederhana yang dibuat untuk menampilkan berbagai pilihan bunga dengan tampilan yang menarik. Website ini juga menyediakan informasi kontak yang dapat digunakan pelanggan untuk melakukan pemesanan dan konfirmasi melalui media sosial.

## ✨ Fitur

- 🌸 Menampilkan berbagai jenis bunga
- 🖼️ Menampilkan gambar dan informasi bunga
- 📋 Informasi produk
- 💬 Konfirmasi dan pemesanan melalui **WhatsApp**
- 📸 Terhubung dengan **Instagram**
- 🎵 Terhubung dengan **TikTok**
- 🎨 Tampilan website menggunakan CSS

## 🛠️ Teknologi

- **HTML5**
- **CSS3**

## 🚀 Menjalankan Project

Clone repository:

```bash
git clone https://github.com/Ramadhani011/Toko-Bunga.git
cd Toko-Bunga
```

Kemudian buka file berikut menggunakan browser:

```text
index.html
```
